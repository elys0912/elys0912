# elys0912

個人で作ったものを置いています。Web（Java・TypeScript主体の）アプリ類と、Firefox の拡張、Claude Code まわりのツールが中心です。

- サイト：https://elysdev.net （作ったものの一覧と説明）
- 雑記：https://elys0912.github.io （作るときに調べたこと、はまったこと）

## 作ったもの

- [claude-discord-channel](https://github.com/elys0912/claude-discord-channel)：Discord から Claude Code に指示を出すブリッジ
- [claude-slack-channel](https://github.com/elys0912/claude-slack-channel)：Slack から Claude Code に指示を出すブリッジ
- [imastodon-inline-visibility](https://github.com/elys0912/imastodon-inline-visibility)：Mastodon の公開範囲を投稿欄の中で切り替えるユーザースクリプト
- [Inari MCP for Firefox](https://github.com/elys0912/InariMCP)：Claude Code から Firefox を操作する拡張（AMO で公開）
- [Layout Toggle for Twitter](https://github.com/elys0912/layout-toggle-for-twitter)：x.com の左メニューと右サイドバーを 1 項目ずつ消せる拡張（AMO で公開）
- [md-json-editor](https://github.com/elys0912/md-json-editor)：Markdown と JSON のビューワー兼エディタ
